# Samaypatra Architecture

## Text Flow

React/Vite
→ API Gateway
→ Lambda
→ Bedrock
→ Structured Event JSON
→ Validation
→ Frontend Review

## Image/PDF Flow

React
→ S3
→ Textract
→ Bedrock
→ Validation
→ Frontend Review

## Calendar Flow

User Confirmation
→ Google OAuth
→ Google Calendar API
→ Calendar Event

## Core Principle

AI proposes.

Our application validates.

The user confirms.

Google Calendar executes.
